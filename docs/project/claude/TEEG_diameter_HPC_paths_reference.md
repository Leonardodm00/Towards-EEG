### 2.2 Spaces in paths and `qsub -v`

`qsub -v` takes a comma-separated list. A value containing a space, such as
the workstream path or the archive root, is fragile there. That is why I_h's
submit script moved its code directory to `PBS_O_WORKDIR`, per the 2026-09-23
entry of the decision log **[KB]**. This job follows the same route:
- `DIAM_CODE` defaults to the submit directory, so it is never passed;
- `DIAM_OUT` defaults to a path with a space, set inside the script, not
  through `-v`;
- **keep `DIAM_CONFIG_JSON` in a path without spaces** (e.g.
  `$HOME/diam/config_production.json`) **[reasoning]**.
