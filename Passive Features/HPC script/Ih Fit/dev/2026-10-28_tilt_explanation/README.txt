TEEG -- checks behind the chat explanations of the tilt sigma_b(c), 2026-10-28 -- standalone, not pipeline code

In the repository since 2026-10-28 (D-097: every document also in the repository). Written in the sandbox for
the noise-fit chat's explanations of 2026-10-28 (Check by computation: each claim was tested on simulated data
before it was written, the prediction and the tolerance fixed before running); their docstrings still say "not
in the repository". Nothing here is imported by the Ih Fit code or runs in a job.

Behind: the explanation of sigma_b(c) and of the three ways to give each twin its tilt SD (per cell, one
cohort value, partial pooling across cells; the tilt study, ../2026-10-26_tilt_sigma_b/, section 3.9); the
brief answers on the semivariogram, the nugget and second-order stationarity; and decision D-100 (2026-10-28:
for the cells with two SS sweeps, per cell and one cohort value both).

check06 and check07 use the tilt study's shared code (../2026-10-26_tilt_sigma_b/scripts: tilt_common.py, and
check04_pooling_options.py for its cohort loader), passed as the first argument, and its banks of simulated
window means, which are not in the repository (about 8 MB). Regenerate them first, in that scripts folder:
    python make_banks.py ref       (~7 min; check07's sanity line)
    python make_banks.py cohort    (~8 min; check06)
then, from this folder:
    python check06_pm_vs_dl.py ../2026-10-26_tilt_sigma_b/scripts
    python check07_tss_window.py ../2026-10-26_tilt_sigma_b/scripts
The other scripts run from this folder with python (numpy; fig_nugget.py also matplotlib). fig01_overview.png
is drawn by Graphviz:  dot -Tpng -Gdpi=150 fig01_overview.dot -o fig01_overview.png

theta_cf = (0.0380 mV, 0.175, 0.0508 mV, 36.6 ms) wherever the noise law enters; the archive's SS layout
(37-pulse trains, 200.5 ms onset to onset, stored (-10, +200) ms windows).
