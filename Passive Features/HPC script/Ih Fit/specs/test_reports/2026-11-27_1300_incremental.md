## Oracles derived from the spec
Written from SPEC 2.11 and the Block 29 entry (with 2.7 (h), Blocks 8, 12, 22, 28) before the code was read.

- O1 path length (2.11). For each node: the sum of the Euclidean distances along its parent chain to the soma's root node. A root is 0. Exact on integer-length 3-D steps (3-4-5, 5-12-13, 2-3-6-7). For a random tree, equal to `scipy.sparse.csgraph.dijkstra` from the root, because in a tree the shortest path is the parent chain. Independent of row order and of id contiguity. Linear-time bookkeeping.
- O2 the step. Radius x f on SWC types 1, 3, 4 when path <= L. The end is closed: a node at path exactly 17 um is inflated at L = 17 and not at L = nextafter(17, 0). Radius x 1 beyond L and on every other type (2, and custom types).
- O3 copy. Ids, types, coordinates, parents and row order unchanged. Radii to 10 significant digits, so relative error <= 5e-10. The header is kept and one comment line added. The source file is untouched.
- O4 limits. f = 1 is the identity. L = 0 inflates the root and any node at path 0. A huge L inflates every type 1/3/4 node and never the axon.
- O5 refusals (ValueError):
  - f not finite or <= 0;
  - L not finite or < 0;
  - dst is src, in any spelling (`..`, symlink);
  - a duplicated id, a parent that is not a node, a cycle (a self-parent included).
  Nothing is written on refusal.
- O6 returned counts: `n_nodes`, `n_inflated`, `n_by_type` (summing to `n_inflated`), `factor`, `max_path_um`.
- O7 plan.
  - The two options are recorded in `run_config.json`'s options only when f != 1. A plan with f = 1 (with any L) compares equal to a plan without the options.
  - Re-planning with other inflation options is refused (exit 3) without `--force`; the same plan is a no-op (exit 0).
  - The manifest does not depend on the inflation.
  - Invalid f or L is "Refused", which in this entry means `Refused` with exit 2 or 3 and nothing written.
- O8 build.
  - `twins/twin_<ID>/sim_morphology_<ID>.swc` = the real reconstruction inflated as O1-O3.
  - The archive's `reconstruction.swc` is the real cell's, byte for byte.
  - `twin.provenance.sim_morphology = {factor, max_path_um, n_nodes, n_inflated, file}`; absent in a plain run.
  - `build_twin(..., sim_swc_path=<missing>)` raises TwinBuildError.
- O9 physics and "every other step unchanged".
  - An inflated twin is exactly a plain twin of a real cell that carries the inflated reconstruction: same truth, stimuli, seeds, noise and features.
  - Hence (noisy - noise-free) is the same in plain and inflated runs.
  - The responses do change.
  - The input resistance falls (M5).
- O10 reuse. An existing archive is reused only when its record equals the run's inflation. Otherwise `twin` fails with the reason (`build_failed`, exit 1). `--force` rebuilds under the new record.
- O11 downstream, unchanged. The fit reads the archive (`morphology_source` = archive, no other morphology in its argv). `sensitivity` builds the twin "as `twin` does", so it builds the inflated twin. `merge` runs.
- O12 reproducibility. Two inflated runs with the same seed give identical archives and identical simulation morphologies.
- O13 the submitter. `DRY_RUN=1 PLAN_ARGS="... --twin-diam-factor F --twin-diam-max-path-um L"` plans, lists and prints the jobs. The jobs carry no inflation flag: the inflation lives in the plan.
