## Problems in the spec

- Block 0 is `Confirmed: inferred` for all six imported modules: `allen_image_io`, `allen_image_align`, `allen_image_measure`, `allen_image_plot`, `smoke_allen_image.py` and `robustness_registration.py`. Their passing suites agree with code the spec entries were written from, which is not independent evidence. In particular the pixel convention (integer full-resolution coordinates = pixel centres, used by Blocks 4 and 5 and by `CropFrame`) and the padding of out-of-image pixels (F5) rest on this inferred code.
- Section 3 says nothing about pixels outside the image within a valid plane. Block 5 says a profile that leaves the image is flagged, but the flag is defined on the block, which always contains the profile (F5).
- Block 4 calls the light-reversal symmetry "exact". It holds only up to the slab discretisation when the grid is not symmetric about c, because the slabs tile [z_min, z_max] from the bottom and the sampled column ranges differ. Measured: 1.3e-4 at `dzeta_um` 0.02 and 1.2e-6 at 0.01.
- Block 5 `stack_edge`: "within `edge_margin_planes` of the first or last usable plane". With margin 1, the code flags only k* equal to that plane (strict `<`). Whether the neighbour of the end plane is "within 1 plane" is not stated.
- Block 10 oracle "window of 10 s": half-width or full width is not stated. A ±5 s window leaves 6e-7 of the Gaussian outside, which is incompatible with the stated 1e-9, so ±10 s was assumed.
- Block 3 names `numpy.polynomial.legendre.leggauss`. The code uses `scipy.special.roots_legendre`, which gives the same rule, so this is not a defect.
- `phantoms.run_replicate` has a `d_override_um` argument (used by `end_to_end.py`) that is not in the Block 6 API. `cell.stretch_branch` has no `types` argument and uses (3, 4) whatever `dendrite_swc_types` says (`cell.py:68`).
- Block 1 does not say whether `CalibrationConfig` belongs in `full_signature()`. The Block 1 oracle "JSON round trip is identity" implies it does (F3).
- Block 6 does not say how `merge` should guard against chunks from another simulator configuration or seed (F6). Block 7's gate 2 states no minimum share of inverted test nodes (F7).
- Block 7 fill with `fill_policy = "none"` and a median window > 1 filters the finite values compacted across NaN gaps, so nodes on either side of a gap become neighbours. The spec's "running median over the filled values" does not say what happens at gaps.
