## Problems in the spec
- S1: `inference.cov_fine_factor`'s default is stated nowhere in Block 30 amendment 3 or Block 36 amendments 22-23. Section 6's wave-7 row says "Gaussian with p/16 error bars 30 s a synthetic node", Block 49's status names "`line_fine_factor` 8 and 32 (the error bars' lattice, D-224.2)", and the code's default is 32 (source D-224.2). At 32 the tester measured 110-120 s per synthetic node for the Gaussian stage (fast configuration, shared CPU).
- S2: Block 30 amendment 3 (B) makes the rows and columns of a parameter at a bound NaN, but does not say how the other entries treat it. The code inverts the full J^T J, with the bound parameter's column taken one-sided: the parameter is treated as free, not held. With xi at `xi_lo` in about half the SGT fits, this convention sets se(d) for those nodes. Coverage was 0.700 under it, inside the band.
- S3: amendment 22 says "fixed (the default) keeps the configuration's table (sigma_r(0) = 0.080 um)" and that `infer_nodes.py` inherits the preparation's renderer, with its own `--kernel-width` re-anchoring the recorded base. In the code an absent switch inherits the preparation's law, which may be calibrated, while an explicit "fixed" returns to the recorded base table. The help text says "Default: fixed".
- S4: the constraints `validate()` adds are not in the spec: `sgt_reach_sigmas >= line_reach_sigmas`; `sgt_samples_per_fwhm >= 2`, while `line_sgt`'s own check accepts 1; `cov_fine_factor` either 0 or at least `line_fine_factor`.
- S5: Block 49 states Z = max(2.1, zeta, 1/zeta), "so that ... the lattices do not change with zeta within its bound". That holds while |ln zeta| <= ln 2.1 = 0.742; `sgt_ln_zeta_bounds` is configurable and `validate()` does not keep it inside that range.
- S6: amendment 22's refusal list does not cover a missing or unreadable `--sigma-json`. The scripts end with a FileNotFoundError traceback (status 1) before writing anything; for the other refusals they give an argparse error (status 2).
- S7: Block 49's oracles (ii) and (iii) name no shape at the corners of the fit's box (beta 1, xi 2, zeta e^+-0.7), which the SGT fit can reach. The tester checked them: all within 1.6e-5.
