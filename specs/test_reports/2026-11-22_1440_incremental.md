## Problems in the spec
- S1 (Block 5 amendment 3 against Block 5's focus rule). Amendment 3 says that under "allen" a node whose traced radius is "not finite and > 0" is fitted and flagged `allen_radius_missing`. Under the default `focus_grad_window = "radius_margin"`, Block 5's focus rule raises ValueError for a missing, non-finite or negative radius before the hold is reached. So, with the defaults, only a radius of exactly 0 reaches the flag; NaN and negative radii end the pilot with ValueError instead (`clean_cell.py` then drops the node). A NaN reaches the flag under `"whole_profile"`. `swc_io.read_swc` accepts all three (checked: a file with radii `nan`, `0.0`, `-0.2` reads as given), so each can reach the pilot. The text should say which outcome is meant for a non-finite or negative radius.
- S2 (Block 27 amendments 3-4): the rule "at least `min_soma_um` from the soma" is silent on `soma_lateral_um` = NaN (no soma); see F2.
- S3 (Block 36 amendment 19 with Block 42's `summarize`). "A node enters the summary when it converged with neither sigma0 nor c at a bound." But `summarize` requires a finite SE_s > 0 for every ok node, and a converged node can have a NaN SE: the pinv path, accepted at Block 42's gate. The script additionally drops such nodes from the summary, yet writes `ok: true` for them in the CSV and the JSON. So the files' `ok` and the summary's membership can disagree, and the spec does not say which is meant.
- S4 (section 6): the table of entry points does not list:
  - `scripts/calibrate_sigma.py`, the entry point of this wave (Block 36 amendment 19);
  - `tests/smoke/test_smoke_line_weights.py` (Block 39);
  - `clean_cell.py clean --no-clean`, `--pilot-diameter` and `--sigma-r0-um`, and `clear --d-bins` (amendments 14-17);
  - `infer_nodes.py real --weights`, `--bump-sd` and `--weight-kappa` (amendment 16).
- S5 (Block 36 amendment 19): the spec is silent on what happens when one node fails (F4), and on whether `--config-json` replaces or amends the record's configuration (F5).
- S6 (Block 40, "Custom code ... Checked"): the claim about `scipy.signal.peak_widths` is inaccurate (F7).
