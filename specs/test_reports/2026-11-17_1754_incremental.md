## Problems in the spec
- S1 (Block 35 amendment 2, oracle (iv)). The slab-grid bound is absolute (5e-4 on S_in), but the move it bounds scales with mu and the dip. With the same geometry (d = 1 um flat, beta 0.14, axis 0.01 um off the plane), linear: 3.3e-4 at mu = 1 /um, 1.0e-3 at mu = 3 /um (the phantoms' upper bound); hybrid at mu = 1: 4.65e-4 (the smoke suite's figure, D-157.2's "thin margin"). The oracle names no mu, so the same code passes or fails depending on a value the spec leaves open. The relative move is about 1.2e-3 of S_in's maximum at both mu.
- S2 (Block 35 amendment 2, edge cases). The text reads "mu = 0 or no planes gives zeros (and, with `layer_um`, `layers` of shape (0, n_planes, n_v) and an empty `layer_z` when the tube has no slab)". At mu = 0 with slabs present, the code returns zero layers over every layer that meets the slabs (n_layers > 0). The tester reads the parenthesis as applying only when there is no slab; the sentence allows both readings.
- S3 (section 6). The table of entry points does not list the new suites `tests/smoke/test_smoke_own_clearance.py` and `test_smoke_own_clearance_figures.py`, nor the `--no-own` flag of `clean_cell.py clean` and `infer_nodes.py real`. Block 37, Block 38 and amendment 11 name them.
- The status vocabulary for a fine fit (F5) and the relation between chord and band (F3), as the triage rows ask.
- No entry in scope is `Confirmed: inferred`.
